FamilyLink Project Images
=========================

Please add the following images to this directory:

Required Images:
1. app_logo.png - Main app logo/icon
2. home_dashboard.png - Home dashboard screenshot
3. member_details.png - Member details sheet screenshot
4. meals_tracker.png - Meals tracking screen
5. meal_calendar.png - Meal calendar view
6. mood_tracker.png - Mood sharing screen
7. mood_history.png - Mood history view
8. interactive_map.png - Family location map
9. events_calendar.png - Events calendar screen
10. family_wall.png - Family wall/feed
11. wall_post.png - Post details or creation
12. profile_stats.png - Profile with statistics
13. settings.png - Settings screen

Image Guidelines:
- Format: PNG recommended
- Resolution: High quality (preferably 1080p or higher for screenshots)
- Aspect ratio: Mobile screens typically 9:19 or 9:20
- File size: Optimize for web (recommended < 500KB per image)

Note: The app_logo.png is the most important - it will be displayed as the main project thumbnail.
